# GMT Scripts — Seismotectonic and Geophysical Mapping of Venezuela

GMT scripts used in the peer-reviewed article by Polina Lemenkova and Olivier Debeir.

**Paper:** Seismotectonics of Shallow-Focus Earthquakes in Venezuela with Links to Gravity Anomalies and Geologic Heterogeneity Mapped by a GMT Scripting Language
**Published in:** *Sustainability* **2022**, *14*(23), 15966
**DOI:** https://doi.org/10.3390/su142315966

## Contents
Generic Mapping Tools (GMT) shell scripts corresponding to Appendix A of the paper, covering five mapping workflows: topographic mapping from GEBCO grids, geoid modelling from EGM2008, free-air gravity and vertical gravity gradient from Scripps/`img2grd` grids, and seismicity mapping of IRIS earthquake events (1997–2021). Includes grid conversion via `gmt grdconvert`, `gmt img2grd` and GDAL, colour-palette generation (`makecpt`), and plotting with `grdimage`, `grdcontour`, `psxy`, `pstext`, `psscale` and `pslegend`.
